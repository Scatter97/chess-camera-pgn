Legacy Revision 35 notes

Revision 35 introduced the main menu, game history, settings, rematches, board options, the Chess960 generator, and the first Opening Explorer.

The project now uses numbered releases instead of revision labels.

Current release: Chess Camera 0.36

Version policy:
- Major features and substantial updates: 0.xx
- Small visual changes and bug fixes: 0.xx.xx

The old run_revision35_* launchers remain for compatibility, but they start the current chess_camera.py entry point.

See README.md, VERSIONING.md, and CHANGELOG.md for current information.
