# Opening books

Place a legal Polyglot opening book in this folder with a `.bin` extension, or choose one from anywhere on your computer through **Opening Explorer → Choose Book**.

Chess Camera reads Polyglot books locally with `python-chess` (`chess.polyglot`). The selected path is saved in `camera_config.json` as `opening_book_path`.

No opening book database is bundled with Chess Camera. Only use book files that you are permitted to use and redistribute.
